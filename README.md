# Tio Thiacqua

Site estático do Tio Thiacqua (Thiago Assumpção) — natação infantil e inclusiva.

Abra `index.html` no navegador; não precisa de instalação nem compilação.
Mantenha a pasta `assets/` junto dos arquivos HTML, CSS e JavaScript.
As fontes (Google Fonts) e os links externos precisam de internet.
